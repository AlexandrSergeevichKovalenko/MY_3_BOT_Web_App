# Пост для пересылки в группы — стратегия правки

Решения владельца, 06.09.2026:
1. Текст поста — **оба варианта** (A 722 знака, B 592) присылаются готовыми, выбор глазами.
2. Картинка — **Феликс с книгой немецкого**, композиция карточки прежняя (плашка + заголовок + 3 галочки + амбер-пилюля).
3. Доставка — **команда `/post`** в боте: приходит в личку, пересылается в группы.

## Что было

- Карточка приглашения рисуется в `backend/share_card.py` поверх позы `brand/felix_original.png`
  (Феликс с зелёной галочкой). Готовый PNG лежит в R2 под ключом с версией.
- Кнопка под фото существовала ТОЛЬКО в inline-режиме (`_handle_share_inline_query`,
  `bot_3.py`): её надо вызывать через `@Ich_Deutsch_bot` в каждом чате отдельно.
- Готового «одного сообщения, которое можно переслать» не было. Длинный пост владельца
  (~1450 знаков) в подпись под фото не влезает: жёсткий лимит Telegram — **1024 знака**
  (`sendPhoto.caption`).

## Что меняем

| Файл | Правка |
|---|---|
| `backend/promo_post.py` | НОВЫЙ. Источник истины для текста поста: два варианта + лимит подписи. |
| `backend/hero_images.py` | Новая поза `book` → `brand/felix_book.png`. `generate_and_upload_hero_images(only=[...])` — генерить ОДНУ позу, а не перерисовывать все четыре рабочих. Неизвестное имя позы → исключение, а не «сделаю все». |
| `backend/share_card.py` | `HERO_R2_KEY` → `brand/felix_book.png`, `CARD_VERSION` → `v2`. Нет Феликса в R2 → карточка НЕ рендерится (см. ниже). |
| `bot_3.py` | `/post` (админ) — фото + подпись + inline-кнопка, по сообщению на вариант. `/admin_hero_images [поза…]` принимает аргументы и после перерисовки `book` сам пересобирает карточку в R2. |
| `backend/admin_command_catalog.py` | Описание `/post` и обновлённое описание `/admin_hero_images`. |
| `backend/tests/test_promo_post.py` | Тест: каждый вариант поста влезает в 1024 знака. |

## Правило ноль: где было тихое ухудшение и что с ним

`render_share_card` раньше при недоступном Феликсе рисовала карточку **без него** и
клала её в R2 под тем же ключом. Кеш держится ВЕРСИЕЙ, а не содержимым, — значит
безлисая картинка осталась бы там навсегда, и никто бы не узнал. Теперь:
нет героя → `render_share_card` возвращает `None` и пишет `logger.error`. Наружу это
видно честно: inline-режим отвечает пустым результатом, `/tour` отдаётся без og:image,
`/post` говорит человеческим текстом «сначала `/admin_hero_images book`».

## Немецкий на картинке

Книгу просим нарисовать с **чистыми страницами** и обложкой в цветах флага. Буквы
запрещены прямо в промпте: gpt-image-1 рисует псевдотекст, и в языковом приложении
это был бы выдуманный немецкий на рекламной картинке.

## Порядок запуска (владелец)

1. Деплой.
2. `/admin_hero_images book` — сгенерит Феликса с книгой, положит в R2, пришлёт превью
   и сразу пересоберёт карточку v2. Не понравился рендер — повторить команду.
3. `/post` — придут оба варианта готовыми сообщениями с кнопкой. Пересылать в группы.
