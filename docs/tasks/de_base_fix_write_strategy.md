# Стратегия ЗАПИСИ правок в немецко-русскую базу

Составлено 15.09.2026, до кода. Основание — диагностика 24 242 записей
(`de_base_defect_full_report.md`) и карта хранилищ.

**Объём:** 925 записей — 729 замен перевода, 137 чисток поля, 59 повторов.
**Не трогаем 23 285 записей (96,2%)**, включая 1 264, которые третья проверка спасла
от правки, и 45, где судьи не сошлись.

---

## 1. Что ЗАПРЕЩЕНО, и почему это не теория

### 1.1 `promote_owner_translation` использовать НЕЛЬЗЯ

Он понижает ВСЕ связи немецкого слова, кроме новой (`database.py:28029-28033`,
условие `WHERE from_unit = %s AND rank < 20 AND to_unit <> %s` — по значению не
фильтрует вовсе).

Замер 15.09.2026 по нашим 702 единицам: **у 603 больше одного значения, у 610 больше
одной связи на русский.** Починка «каблука» у `der Absatz` понизила бы «абзац» и «сбыт».
Пострадали бы 610 единиц из 702.

**Правим СВЯЗЬ КОНКРЕТНОГО ЗНАЧЕНИЯ** (`bt_3_lex_links.sense_id`), а не слово целиком.

### 1.2 Текст русской единицы не переписываем никогда

Одна русская единица обслуживает до 12 немецких слов. `UPDATE bt_3_lex_units SET
display=...` запрещён абсолютно. Нужную единицу ищем через `ensure_unit(текст, "ru")` —
она переиспользует существующую по указателю, а не заводит вторую.

### 1.3 `bt_3_user_word_overrides` не трогаем

Что человек вписал руками, побеждает всё (`database.py:5565-5569`) и остаётся его.
Если у карточки есть override на `translation_ru` — личную карточку пропускаем,
общий слой чиним.

### 1.4 Никаких `LIKE` и подстрок

Только точное равенство поля целиком. «расслаблять» может быть законным переводом
другого немецкого слова.

## 2. Порядок записи. Нарушение порядка откатывает починку САМО

    1. связь значения      bt_3_lex_links        ← источник правды
    2. карточка слова      bt_3_lex_units.card   ← синхронизировать
    3. пул и кеш           DELETE обеих копий    ← ТОЛЬКО ПОСЛЕ 1 и 2
    4. личные карточки     колонка + response_json
    5. письмо человеку     что было / что стало

**Почему 3 именно третьим.** У кеша выдачи нет срока годности («живёт годами»).
Если снести его до правки — первый же поиск соберёт кеш заново со СТАРЫМ переводом,
получит свежую метку времени, и починка тихо откатится.

---

## 3. Как правится связь значения

Для записи «(немецкая единица U, значение S): было X, станет Y»:

1. `new_to = ensure_unit(Y, "ru")` — найти или завести русскую единицу Y.
2. Если связь `(U → new_to)` уже есть у ДРУГОГО значения — конфликт по
   `UNIQUE (from_unit, to_unit)`. Такую запись НЕ чиним автоматически, откладываем
   в отчёт: у слова два значения ведут к одному русскому слову, это разбирается руками.
3. Иначе: `INSERT (U, new_to, sense_id=S, rank=1, source='вычитка')`.
4. Старую связь `(U → X)` **только если её `sense_id` равен S**:
   понизить до `rank = GREATEST(rank, 20)`. НЕ удалять — вдруг она верна как
   второстепенный вариант, и удаление решало бы за человека.
5. Связи ДРУГИХ значений этого слова не трогать ни одной.

Для записей без значения (86 предложений): та же логика по `to_unit = X`,
условие на `sense_id IS NULL`.

## 4. Чистка поля и повторов — без модели

**137 «мусор в поле»:** в русском поле лежит немецкий текст, стрелка «->», склейка
двух предложений. Чинится разбором строки: взять часть после «->» или отрезать
немецкую половину. Каждое правило — с проверкой «получилось ли по-русски»
(нет латиницы больше порога). Не получилось — не трогаем, кладём в отчёт.

**59 «повтор варианта»:** «поймать; поймать» → «поймать». Разбить по `;` и `,`
(у предложений — только по `;`, иначе режем текст), убрать точные повторы,
собрать обратно. Порядок оставшихся сохранить.

---

## 5. Копия до правки — обязательна

Перед КАЖДОЙ изменённой записью в файл пишется её прежнее состояние: id, все
затронутые поля, время. Файл ложится в репозиторий рядом со скриптом.
Без записи копии правка не выполняется — это условие в коде, а не обещание.

Откат: отдельный скрипт, который читает файл копий и возвращает всё как было.
Он пишется ВМЕСТЕ с правкой, а не потом.

## 6. Порядок выката

    Шаг 1. Сухой прогон: ничего не пишем, печатаем что СОБИРАЕМСЯ сделать
           по каждой из 925 записей. Владелец смотрит.
    Шаг 2. Первая пачка 20 записей. Пишем. Владелец открывает экран и проверяет.
    Шаг 3. Остальные 905, если пачка прошла.
    Шаг 4. Письма людям: что было / что стало.

Между шагами — слово владельца. Без него следующий шаг не начинается.

---

## 7. Чего эта правка НЕ делает

- Не чинит **пояснения значений**. Встречались записи, где неверен не перевод, а само
  пояснение (`jemanden abschieben` с пояснением «переносить что-то куда-либо»).
  Это отдельный класс и отдельная задача.
- Не трогает **32 записи**, где негодна сама предложенная замена — их надо переспросить.
- Не трогает **45 записей**, где три судьи не сошлись.
