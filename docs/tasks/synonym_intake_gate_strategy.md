# Дверь приёма синонимов спринта/тренажёра — стратегия (06.09.2026)

## Повод

Пользователь: «из 8 раз в 5 был вариант die Option». Экран тренировки синонимов
`die Gelegenheit`: «die Option» шесть раз в чипах и в раундах.

Замер 06.09.2026 (живая база, три независимые проверки сошлись):

| Что | Сколько |
|---|---|
| Записей банка `bt_3_sprint_bank` | 56 (24 synonym, 32 antonym) |
| Записей с одним словом дважды в `accepted` | 9 (все synonym), 19 лишних строк |
| Записей, где в `accepted` лежит само целевое слово | 4 |
| Существительных-синонимов с артиклем НЕ по справочнику рода | 4 (die Potenzial, die Backup, die Beistand, das Konsens) |
| Пар «слово → синоним» (после дедупа, без самослова) | 405 |
| … подтверждает OpenThesaurus в одном гнезде | 146 |
| … OpenThesaurus не знает синонима вообще | 23 (rememembern, ererkennbar, entschlüssen, …) |

Корень один: список `accepted` пишет модель по промпту «18–35 синонимов, как можно
больше» и он идёт в базу без единой проверки (`bot_3._sprint_topup` → `upsert_sprint_item`).
Прежний случай того же класса (самослово) чинили тремя фильтрами ниже по течению
(`answer_eval.load_trainer_task`, `TrainerGame.buildRounds`), а не на входе.

## Решение владельца (06.09.2026, дословно по пунктам: «ok»)

1. Дубли и самослово убираются на входе.
2. Каждый синоним обязан подтвердиться хотя бы одним источником: OpenThesaurus или
   `{{Synonyme}}` немецкого Wiktionary. Не подтвердился — не показывается, считается,
   уходит владельцу пачкой с кнопками «оставить / убрать». **Требование владельца:**
   в письме у кандидата стоят артикль, перевод и вердикт справочника, иначе решать не по чему.
3. Артикль каждого существительного сверяется со справочником рода
   (`article_authority.authoritative_article`). Расхождение или «не знаю» — не показывается,
   уходит владельцу с тем же письмом (для «не знаю» — кнопки der/die/das).
4. Слово принимается от **трёх** подтверждённых синонимов; квота «18–35» из промпта убрана.
   Восемь раундов не цель: «не у каждого слова есть восемь синонимов, начнёт выдумывать».
5. Накопленное чистится **тем же правилом**, а не руками.

## Что строим

- `bt_3_openthesaurus_synsets` — офлайн-выгрузка OpenThesaurus (LGPL, 48 484 гнезда),
  загрузчик `scripts/load_openthesaurus.py`, дата выгрузки в `bt_3_admin_kv`.
- `bt_3_wiktionary_synonyms` — кеш секций `{{Synonyme}}` / `{{Gegenwörter}}` de.wiktionary,
  ходок тот же, что у рода (`article_wiktionary_ref._fetch_wikitext`, пачки по 45).
- `backend/synonym_sources.py` — читатели обоих источников, один ответ «подтверждено чем».
- `backend/sprint_intake.py` — дверь `clean_accepted(...)`: дедуп → самослово → артикль →
  подтверждение → порог 3. Одна функция и для нового слова (`_sprint_topup`), и для
  накопленного (ночная гигиена `sprint_bank_hygiene`, 03:10, и скрипт
  `scripts/sprint_bank_hygiene.py --dry-run/--apply`).
- `bt_3_sprint_accepted_review` — очередь кандидатов владельцу; письмо
  `backend/sprint_accepted_review.py` (ежедневно 12:45, пачка 20 — решение владельца, образец —
  `article_retire_review.py`), кнопки `sacc:<keep|der|die|das|drop>:<id>`,
  команда `/admin_synonym_review`.
- Строка «🧩 Синонимы» в утреннем отчёте «Ночной добор словаря».
- Обещания в `backend/fix_promises.py`: `sprint_accepted_duplicates`,
  `sprint_accepted_article_mismatch`, `sprint_bank_unchecked`.

## Судья (владелец 06.09.2026, второй заход)

Сухой прогон двери оставил владельцу 258 кандидатов. Владелец: «если модель говорит да —
зачем я? если нет — тоже зачем я?» Решение («делай»):

- всё, что дверь не пропустила и что требует решения, сперва судит модель ПОДСТАНОВКОЙ
  (`backend/synonym_judge.py`): предложение с исходным словом → то же с кандидатом →
  «да» / «нет» / «сомневаюсь» + причина по-русски + пара предложений;
- голос чужой (Gemini), запасной gpt-4.1; кто судил — в строке и в утреннем отчёте;
  06.09 Gemini без кредитов («prepayment credits are depleted»), судил GPT;
- «да» входит в список само (существительное — с артиклем справочника), «нет» снимается
  само; владельцу — только «сомневаюсь» и «да» при неизвестном справочнику артикле;
- антонимы: та же дверь (подтверждение `{{Gegenwörter}}`, порог 3, судья), промпт без
  квоты 12–25;
- примеры «верного выбора» у кандидата живут до решения; снятому стираются; принятым без
  примера дособираются (`backfill_missing_examples`, 1 запрос на слово, ночью после судьи);
- обещание `sprint_review_unjudged_stale`: без вердикта старше двух суток — 0.

## Что НЕ трогаем (границы)

- Подтверждение «через соседнее гнездо» OpenThesaurus (hop1, +87 пар) НЕ считается

## Второй заход: человека из цепочки убрать (владелец, 08.09.2026)

Повод. Экран тренажёра антонимов «unabhängig» 08.09 09:25: три антонима. Замер
(живая база 08.09 18:32 UTC): модель предложила 9, Wiktionary подтвердил 1 (abhängig),
судья — «да» 2, «нет» 1, «сомневаюсь» 5, и эти пять ждали письма владельцу 10.09 (позиции
33–37 из 65 в очереди по 20 в день). По банку: у синонимов два источника и 16 слов из 27
с 8+ ответами; у антонимов один источник (Gegenwörter, у 9 из 32 слов пуст) и ни одного
слова с 8+; антонимов было ≥238, стало 136.

Владелец, дословно: «я не понимаю, зачем мне вообще высылается это на согласование.
Я человек, не модель, я всё равно пойду советоваться с моделью или со словарём. Нам нужно
построить схему, при которой модель не будет сомневаться и при которой я не буду
участвовать вообще. Модель ставит итоговую точку.» Пункты 1–4 — «ok. Do it».

### Решение (все пункты подтверждены владельцем 08.09.2026)

1. **Генератор даёт полный список.** Из промптов `sprint_synonym` / `sprint_antonym`
   убрана фраза «lieber 4 echte als 15/20 erzwungene»: модель не урезает сама, отсев —
   дверь и судья. Порог «минимум 3 существуют» остаётся.
2. **Косвенная антонимия — второй источник для антонимов, только из словарей.**
   «X — противоположность цели по Wiktionary ({{Gegenwörter}})» + «кандидат лежит с X
   в одном гнезде OpenThesaurus» ⇒ кандидат подтверждён (`confirmed_by=['indirect']`,
   `via=X`). Это метод WordNet/GermaNet (indirect antonymy через голову пары).
   Владелец: «мы сами не будем придумывать, добавляя приставку un» — никакой
   морфологии, только два словарных факта. Симметрично: противоположность КАНДИДАТА
   по Wiktionary в одном гнезде с ЦЕЛЬЮ — тоже подтверждение.
   Оговорка (записана, владельцу названа): гнёзда OpenThesaurus разбиты по значению, но
   какое гнездо головы отвечает значению цели, словари не говорят; поэтому «süchtig»
   (гнездо «körperlich abhängig») подтвердится как антоним «unabhängig» так же, как
   «unfrei». Это тот случай, о котором спрашивал пользователь.
3. **Слово обязано существовать.** Однословный кандидат, у которого нет страницы в
   Wiktionary И которого не знает OpenThesaurus, снимается ДО судьи
   (`reason=no_dictionary`, status='removed', decision='no_dictionary'). Повод:
   «befehlsgebunden» (нет в Duden, DWDS, Wiktionary) вошёл по «да» судьи. «Не удалось
   проверить» (сеть) — не «нет страницы»: такой кандидат идёт судье.
   Обороты из нескольких слов существованием не проверяются — их судит судья.
4. **Судья ставит точку.** Вердикт только «yes»/«no», варианта «unsure» нет. Голосов —
   три (`SYNONYM_JUDGE_VOTES`, решение владельца 08.09), большинство от дошедших, ничья
   = «нет», ни одного голоса — не судили, ночь повторит. Из задания судьи убрана
   неверная посылка «два словаря НЕ подтвердили» (для антонимов спрашивали один) и
   установка «be conservative»; критерий — «включил бы редактор Duden Synonymwörterbuch
   в статью цели в этом значении (пометка регистра допустима)».
5. **Артикль неизвестен справочнику** — единственное «не знаю» в схеме. При «да» судьи
   справочник рода спрашивается с сетью (Wiktionary); нашёлся — слово входит с артиклем
   справочника; нет — слово снимается (`decision='article_unknown'`) и СЧИТАЕТСЯ в отчёт
   как задача на справочник. Владельцу на кнопку не уходит.
6. **Тонкое слово при наборе не выбрасывается молча.** Меньше трёх подтверждённых —
   запись кладётся в банк снятой (`retired`, `thin_accepted`), кандидаты — судье; набрал
   три — возвращается сам (`apply_decision`, unretire). Раньше слово с 9 кандидатами
   и одним подтверждённым исчезало без суда.
7. **Дверь помнит решения.** `clean_accepted` получает множество уже принятых
   (status='kept' в очереди) и не режет их повторно — иначе `--recheck` снимал бы
   принятое судьёй слово молча (найдено трассировкой 08.09, в ночном прогоне не
   проявлялось, потому что запись проверяется один раз).
8. **Письмо 12:45 с кнопками отменено.** Задача планировщика снята, строка здоровья
   снята. Кнопки на старых письмах работают (обработчик оставлен). Вместо письма —
   строка «🧩 Дверь синонимов» в утреннем отчёте: сгенерировано / подтвердили словари
   (прямо, косвенно) / судья да-нет / снято без словаря / без артикля / ждут судью.
9. **Накопленное:** 65 открытых карточек (60 «сомневаюсь» + 5 «да при неизвестном
   артикле») пересуживаются новым судьёй той же ночью (03:10) и сразу после деплоя
   скриптом `scripts/sprint_bank_hygiene.py --judge --apply`. Уже принятые решения
   владельца (keep 37, drop 21, der/die/das 2) не трогаются. Слова, лежащие в accepted
   без словарной страницы, снимаются перепроверкой (`--recheck`, теперь безопасной).
10. **Обещания** (`backend/fix_promises.py`): `sprint_review_open_stale` — открытых
    карточек старше двух суток 0 (никто никого не ждёт); `sprint_accepted_no_dictionary`
    — слов в показе без словарной страницы 0; экран «после» — списки антонимов
    «unabhängig» и синонимов «die Gelegenheit» три утра подряд.

Что НЕ меняется: дедуп, самослово, артикль по справочнику, порог показа 3, правила
игры. Три голоса при temperature 0 одной модели дают мало независимости (12% разнобоя,
замер 16.08); это названо владельцу, число голосов — его решение и живёт в одной
переменной.
