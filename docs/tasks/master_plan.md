Живой документ. Ведётся с 16.08.2026, обновляется после каждой закрытой задачи.
Основа — аудит 92 находок (артефакт «Карта костылей»), свёрнутых в 7 корней.

**Зачем всё это.** Приложение должно давать человеку идеальный опыт: быстрый ответ,
чистый путь между вопросом и ответом, тяжёлое — в фоне, честные подсказки вместо
сырых ошибок. И ни одной выдуманной формы немецкого языка.

- формы существительных, прилагательных и наречий читаются из напечатанной таблицы
  de.wiktionary; арифметика удалена из движка;
- каскад: справочник → разбор составного слова по доказанному шву → модель с двумя
  совпавшими ответами → остаток владельцу;
- ночная работа идёт тем же путём, что разовая чистка (новое слово не повторяет историю);
- накопленное вычищено: 463 выдуманные таблицы, 47 негодных заголовков починено

## З. Одна дверь сохранения слова (поставлена 19.08.2026)

Владелец: «Мы обязательно должны проверять ПЕРЕД сохранением… найти, откуда происходит
некорректное сохранение, проверить ВСЕ пути, свести их в единый механизм без костылей.
Сначала свериться со всеми справочниками, при недостатке — с моделью. Наша задача —
сохранить правильную версию слова или предложения: грамматически, лексически, с верной
заглавной буквой, с верной частью речи и обогащением.»

**Что входит в задачу:**

1. Найти ВСЕ пути, которыми слово/фраза попадает в базу (мини-апп, бот, ярлык, импорт,
   ночные работы, разборы). Составить карту с `file:line`.
2. Свести их в одну дверь. Правило: мимо двери в базу не попадает ничего.
3. Дверь проверяет по порядку: существует ли слово → правильное ли написание (умлауты,
   ß/ss, обрезка) → регистр по части речи (существительное с заглавной, глагол со
   строчной) → часть речи из справочника → формы → обогащение.
4. Источники по убыванию доверия: справочник → разбор составного слова → модель с двумя
   совпавшими ответами. Ничего не выдумывать, ничего не глушить.
5. Что дверь не смогла подтвердить — не выбрасывается молча, а идёт в разбор.

**Отдельная часть — разбор с ПОЛЬЗОВАТЕЛЕМ (не с админом):**

Раз в неделю или месяц человеку приходит в личку короткое сообщение: «вот слова, которые
ты сохранил, а мы не смогли подтвердить». К нему — чекбоксы. Отмеченные остаются,
неотмеченные удаляются везде: из его словаря, из общего пула, из всех таблиц.

Открытый вопрос владельца: как быть, когда слово человека устраивает, а перевод нет.
Обсудить до реализации.

## Как ведётся работа

Каждая задача — по замкнутому циклу из `CLAUDE.md` (9 шагов): анализ несколькими
агентами → чужие решения → обсуждение → чистка накопленного → перестройка системы →
автомат ночью → сомнения владельцу с кнопками → отчёт сам, без команды.

**После каждой закрытой задачи возвращаемся сюда и берём следующую группу.**
Углубление в отдельную задачу нормально, но план не теряется.
